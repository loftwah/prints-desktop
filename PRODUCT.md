# Product

Prints Desktop is an independent native creative workspace for existing Prints
users and people curious about creating and keeping their own media. Its first
launch opens an offline collection so people can inspect, shortlist, and export
artwork before connecting any service.

## Platform and stack

Desktop. Native Rust and Anomaly's Rune, with Apple Silicon first and Windows
and Linux intended. App Composer provides discovery and education. Oyster,
Prints and Darkroom retain authority over hosted assets, models, jobs and
billing. A compatible scoped connection is required for remote work.

Source of truth: [App Composer #1292](https://github.com/loftwah/app-composer/issues/1292).
