# Loftwah Creative Archive

The first edition follows three published projects. LoftwahFM’s album cover,
venue poster and short fiction artwork show how one release takes different
forms. Fighter’s ringside study follows an existing game poster into Media
Studio. Bubbles’ One Shot captures an actual game moment and turns it into
a poster. Afterlight remains a separate bundled collection.

The bundled files are unmodified copies of the public assets. No private
drafts or third-party source artwork are included. Loftwah authorises their
distribution with Prints Desktop and individual original-file exports.
Portfolio marks and artwork retain their original ownership. The
repository's MIT software licence applies to the software.
